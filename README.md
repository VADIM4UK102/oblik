# oblik
RESALE — PWA (встановлюваний вебзастосунок)

Файли:
- index.html — програма
- manifest.webmanifest — опис застосунку
- sw.js — кешування для роботи офлайн

ВАЖЛИВО: встановлення як справжнього PWA потребує розміщення цих файлів на HTTPS-хостингу (наприклад, GitHub Pages або Netlify). Відкриття HTML-файлу напряму з пам'яті телефону дає змогу користуватися програмою, але не активує повне PWA-встановлення та офлайн-кеш.

Після публікації HTTPS-адреси відкрий її в Chrome Android → меню ⋮ → «Установити додаток» / «Додати на головний екран».

Дані зберігаються локально в браузері. Робіть резервну копію в Налаштуваннях.
